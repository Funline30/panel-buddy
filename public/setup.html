Firestore security rules

Firebase console → Firestore Database → Rules tab → select everything in the box and delete it → paste this → Publish.

rules_version = '2';

// Panel Buddy - Firestore security rules.
// Each signed-in user can read and write ONLY their own data under users/{their uid}/.
// Nobody (signed in or not) can read anyone else's data.
service cloud.firestore {
  match /databases/{database}/documents {

    function isOwner(uid) {
      return request.auth != null && request.auth.uid == uid;
    }

    function knownCollection(col) {
      return col in ['homes', 'panels', 'breakers', 'devices', 'photos'];
    }

    match /users/{uid}/{col}/{docId} {
      allow read, delete: if isOwner(uid) && knownCollection(col);
      allow create, update: if isOwner(uid)
        && knownCollection(col)
        && (col != 'photos'
            || (request.resource.data.data is string
                && request.resource.data.data.size() < 900000));
    }

    // Everything else is closed.
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

What it does: each signed-in person can read and write only their own data (under users/their-id/). Everything else is locked.

Authorized domain (after Vercel)

Firebase → Authentication → Settings → Authorized domains → Add domain → paste your Vercel address without https:// (for example panel-buddy.vercel.app).
